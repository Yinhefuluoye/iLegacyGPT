# iLegacyGPT v1.0.0

**A large-language-model client for old iOS devices.** First public release; tested on iPad 4 (iPad3,4 / A6X / armv7 / iOS 10.3.4).

## Features

- Connects to any **OpenAI-compatible API** — provider / base URL / port / key are configurable, the model list is fetched live;
- **Streaming output** with a visible **reasoning** block (off / low / medium / high; parameters are customizable);
- **Session archive** — left drawer grouped by Today / Last 7 days / Earlier, swipe to rename or delete;
- **Image input** — pick from the photo library; history keeps a 320 px thumbnail;
- **Local-only data** — no account, no telemetry, keys and sessions stay in the app sandbox;
- Tuned for iOS 10 WebKit: no optional chaining, no flex `gap`, no `inset`, no `backdrop-filter`.

## Install

1. Requires **AppSync Unified** (or a self-signing tool);
2. Download `iLegacyGPT-1.0.0.ipa` and install with i4Tools / ipatool / any self-signing tool;
3. Open settings and fill in provider, base URL, port and API key.

> Unsigned build, no Apple assets, for personal devices you own.

## Verify

```
sha256 in iLegacyGPT-1.0.0.sha256
```

## Known limitations

- armv7 only (32-bit);
- history images are 320 px thumbnails, originals are not persisted;
- reasoning levels only work if your gateway honours the parameters;
- first load is a bit slow on old hardware.

## Disclaimer

Not affiliated with OpenAI; `GPT` refers to general-purpose large language models. This project ships no API key and no proxy. Provided "as is".

# 中文说明

**给老 iOS 设备用的大模型客户端。** 首个公开版本，在 iPad 4（iPad3,4 / A6X / armv7 / iOS 10.3.4）上实测可用。

## 功能

- 连接任意 **OpenAI 兼容接口**：provider / Base URL / 端口 / API Key 全部可配，模型列表自动拉取；
- **流式输出**，并可显示**思考过程**（关闭 / 低 / 中 / 高四档，参数可自定义）；
- **会话归档**：左侧抽屉按「今天 / 近 7 天 / 更早」分组，左滑重命名 / 删除；
- **图片上传**：相册选图发送，历史保留 320px 缩略图；
- **数据只存本机**：无账号、无遥测，Key 与会话都在 App 沙盒内；
- 为 iOS 10 的 WebKit 定制：无可选链、无 flex `gap`、无 `inset`、无 `backdrop-filter` 等新特性。

## 安装

1. 需要设备已越狱并安装 **AppSync Unified**（或可自签名）；
2. 下载 `iLegacyGPT-1.0.0.ipa`，用爱思助手 / ipatool / 自签名工具安装；
3. 打开后进设置填写 provider、Base URL、端口、API Key。

## 已知限制

- 只编了 armv7（32 位），64 位设备装不上；
- 历史图片仅存 320px 缩略图，原图不落盘；
- 思考档位是否生效取决于所用网关；
- 老设备首次加载略慢。
