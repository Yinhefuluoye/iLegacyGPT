# iLegacyGPT v1.2.0

> **Pre-release / 未实测**：本版把支持范围扩大到 iOS 9.3.5 与 64 位设备，但只在 iPad 4 / iOS 10.3.4 上验证过。iOS 9.3.5 与 arm64 路径为**静态验证通过、未在真机运行**。
> **Pre-release**: adds iOS 9.3.5 and 64-bit device support. Only iOS 10.3.4 on iPad 4 is tested; the iOS 9.3.5 and arm64 paths are verified statically, not on hardware.

## What changed

- **armv7 + arm64 fat binary** — one IPA now installs on both 32-bit (iPad 4, iPhone 5/5c) and 64-bit devices (iPhone 5s … 7) that run iOS 9 or 10;
- **UI bundle is now ES5** — the TypeScript is compiled to ES5 by the project's own `tsc` before bundling (esbuild cannot lower to ES5). This is what iOS 9.3.5 WebKit needs: it has no `let`, no arrow functions, no `class`;
- **deployment target 9.3** — `MinimumOSVersion` is 9.3 (CSS custom properties, used throughout, arrived in 9.3);
- build-time guard: the bundle is parsed again with an ES5 target and rejected if any ES2015 syntax survives.

## Install

1. Requires **AppSync Unified** (or a self-signing tool);
2. Download `iLegacyGPT-1.2.0.ipa`; i4Tools / ipatool pick the matching slice automatically;
3. Configure provider, base URL, port, API key.

sha256 in iLegacyGPT-1.2.0.sha256

Known unverified risks on iOS 9: flexbox on Safari 9 has layout bugs, and the software keyboard interacts differently with a fixed composer.

## Known limitations

- the follow-up round after a tool call injects search results as context instead of replaying `tool_calls`;
- history images are 320 px thumbnails;
- reasoning levels depend on the gateway;
- the app is unsigned — sign it yourself.

# 中文说明

> **预发布 / 未实测**：本版把支持范围扩到 iOS 9.3.5 与 64 位设备，但只在 iPad 4 / iOS 10.3.4 上验证过。iOS 9.3.5 与 arm64 路径是**静态验证通过、未在真机跑过**。

## 变更

- **armv7 + arm64 双架构**：同一个 IPA 既能装 32 位机（iPad 4、iPhone 5/5c），也能装跑 iOS 9/10 的 64 位机（iPhone 5s ~ 7）；
- **界面 JS 改为 ES5**：先用项目自带的 `tsc` 把 TypeScript 降到 ES5 再打包（esbuild 不支持降到 ES5）。iOS 9.3.5 的 WebKit 没有 `let`、箭头函数、`class`，这一步是必需的；
- **部署目标降到 9.3**：`MinimumOSVersion = 9.3`（全站使用的 CSS 自定义属性正是 9.3 才有的）；
- 构建时守卫：产物会再用 ES5 目标解析一次，一旦残留 ES2015 语法就直接让构建失败。

## 安装

1. 需要 **AppSync Unified**（或可自签名工具）；
2. 下载 `iLegacyGPT-1.2.0.ipa`，爱思助手 / ipatool 会自动选匹配的架构；
3. 进设置填写 provider、Base URL、端口、API Key。
