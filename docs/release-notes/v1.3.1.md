# v1.3.1

## Added

None.

## Changed

- `Icon-1024.png` and `icon-master.png` are no longer part of the application bundle. Neither file is referenced by `Info.plist`, and iOS reads application icons up to 167 px from `CFBundleIconFiles`; the two files were copied into the bundle only because they shared the resources directory. The IPA decreases from 1,484,598 bytes to about 215 KB.
- The 1024 marketing image is retained as `docs/assets/icon-source.png` for documentation and store listings.
- `tools/make_app_icons.py` writes device sizes only, and takes `--marketing PATH` to emit the 1024 image outside the bundle.

Device icons are unchanged: the nine PNG files in the bundle are the same files as in v1.3.0, generated from the same lossless source.

## Fixed

None.

## Known issues

- armv7 on iOS 9.3.5 / 9.3.6 and arm64 on iOS 9 / 10 are not verified on hardware;
- the follow-up request after a search tool call carries the retrieved documents as context; the `tool_calls` messages are not replayed;
- conversation images are stored as 320 px thumbnails;
- the IPA is unsigned and requires AppSync Unified or re-signing.

# v1.3.1

## 新增

无。

## 变更

- `Icon-1024.png` 与 `icon-master.png` 不再进入应用包。两者均未被 `Info.plist` 引用，且 iOS 只从 `CFBundleIconFiles` 读取至多 167px 的图标；此前被一并打包，仅因它们与图标同处资源目录。IPA 由 1,484,598 字节降至约 215 KB。
- 1024 展示图保留为 `docs/assets/icon-source.png`，供文档与商店展示使用。
- `tools/make_app_icons.py` 只生成设备尺寸，并通过 `--marketing PATH` 将 1024 图输出到包外。

设备图标未变：包内的 9 张 PNG 与 v1.3.0 完全一致，出自同一份无损源图。

## 修复

无。

## 已知问题

- armv7 + iOS 9.3.5 / 9.3.6 与 arm64 + iOS 9 / 10 未经真机验证；
- 检索工具调用后的续接请求以上下文形式携带检索结果，不重放 `tool_calls` 消息；
- 会话图片以 320px 缩略图保存；
- IPA 未签名，需 AppSync Unified 或自行签名。
