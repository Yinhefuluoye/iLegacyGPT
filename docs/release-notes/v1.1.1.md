# iLegacyGPT v1.1.1

**A large-language-model client for old iOS devices.** Same code as v1.1.0 — this release only corrects the declared minimum system version.

## What changed

- `MinimumOSVersion` is now **10.0** (was 8.0). The UI bundle is ES2015 and the stylesheet uses CSS custom properties, so anything below iOS 10 would install and then show a blank page. Declaring 10.0 keeps iOS 8/9 devices from installing a build that cannot run.
- No functional changes: web search (off / auto / force, real function calling), markdown tables, thinking levels and everything else are identical to v1.1.0.

## Install

1. Requires **AppSync Unified** (or a self-signing tool);
2. Download `iLegacyGPT-1.1.1.ipa` and install with i4Tools / ipatool / any self-signing tool;
3. Open settings, fill in provider, base URL, port and API key.

## Verify

```
sha256 in iLegacyGPT-1.1.1.sha256
```

## Compatibility

| | Status |
| --- | --- |
| iPad 4 (iPad3,4, A6X, armv7) | ✅ tested on iOS 10.3.4 |
| Other armv7 devices on iOS 10 (iPhone 5 / 5c) | ⚠️ untested, should work |
| iOS 8 / 9 devices | ❌ not supported by this build |
| 64-bit devices | ❌ this build is armv7 only |

Not affiliated with OpenAI; `GPT` refers to general-purpose large language models. This project ships no API key and no proxy. Provided "as is".

# 中文说明

**给老 iOS 设备用的大模型客户端。** 代码与 v1.1.0 完全相同，只修正了声明的最低系统版本。

## 变更

- `MinimumOSVersion` 由 8.0 提高到 **10.0**。界面 JS 是 ES2015、样式用了 CSS 自定义属性，低于 iOS 10 的设备装得上但会白屏；声明 10.0 可以避免 iOS 8/9 设备装一个跑不了的包。
- 功能零变化：联网搜索（关闭 / 自动 / 强制，真 function calling）、Markdown 表格、思考档位等都与 v1.1.0 一致。

## 安装

1. 需要设备已越狱并安装 **AppSync Unified**（或可自签名）；
2. 下载 `iLegacyGPT-1.1.1.ipa`，用爱思助手 / ipatool / 自签名工具安装；
3. 打开后进设置填写 provider、Base URL、端口、API Key。

## 校验

```
sha256 见 iLegacyGPT-1.1.1.sha256
```
