# v1.3.0

## Added

- New application icon set, generated from a 1024 x 1024 source stored at `docs/assets/icon-source.png`. Every size is a direct downscale of the source: the artwork is neither cropped nor re-composed.

## Changed

- `tools/make_app_icons.py`: `--fill` defaults to 0, so the master is preserved by default. A new `--exact` mode pads a non-square master with the background colour instead of cropping it.
- The logo at the top of both README files is the new artwork, scaled directly from the same source.

## Fixed

None.

## Known issues

- armv7 on iOS 9.3.5 / 9.3.6 and arm64 on iOS 9 / 10 are not verified on hardware;
- the follow-up request after a search tool call carries the retrieved documents as context; the `tool_calls` messages are not replayed;
- conversation images are stored as 320 px thumbnails;
- the IPA is unsigned and requires AppSync Unified or re-signing.

# v1.3.0

## 新增

- 新的应用图标集，源文件为 `docs/assets/icon-source.png`（1024 x 1024）。各尺寸均由源图直接等比缩小，未裁切、未重新构图。

## 变更

- `tools/make_app_icons.py`：`--fill` 默认值改为 0，默认保留源图；新增 `--exact` 模式，非正方形源图以背景色补边而非裁切。
- 两个 README 顶部的 logo 更换为新图，同样由该源图直接缩放。

## 修复

无。

## 已知问题

- armv7 + iOS 9.3.5 / 9.3.6 与 arm64 + iOS 9 / 10 未经真机验证；
- 检索工具调用后的续接请求以上下文形式携带检索结果，不重放 `tool_calls` 消息；
- 会话图片以 320px 缩略图保存；
- IPA 未签名，需 AppSync Unified 或自行签名。
