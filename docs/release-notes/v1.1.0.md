# iLegacyGPT v1.1.0

**A large-language-model client for old iOS devices.** Replaces v1.0.0; tested on iPad 4 (iPad3,4 / A6X / armv7 / iOS 10.3.4).

This release adds **live web search** and fixes the two issues reported against 0.7.x (thinking could not be turned off, markdown tables did not render).

## Features

- Connects to any **OpenAI-compatible API** — provider / base URL / port / key are configurable, the model list is fetched live;
- **Web search** with three modes: off / auto / force;
  - **auto** uses **real function calling** — a `web_search` tool is advertised and the model itself decides whether to search; results come back as numbered sources with clickable links;
  - **force** always searches first, then answers with the results injected;
  - endpoints that reject `tools` (HTTP 400/422) fall back to a search planner automatically;
- **Streaming output** with a visible **reasoning** block (off / low / medium / high);
  - turning thinking **off** now really disables it (`enable_thinking: false`), instead of relying on the gateway default;
- **Markdown** — pipe tables with column alignment, wide tables scroll sideways, plus task lists, nested lists, strikethrough, bare-URL links and code blocks;
- **Clock context** — the model is told the current time and zone, so "today / latest" questions search with the right date;
- **Session archive** — left drawer grouped by Today / Last 7 days / Earlier, swipe to rename or delete;
- **Image input** — pick from the photo library; history keeps a 320 px thumbnail;
- **Local-only data** — no account, no telemetry, keys and sessions stay in the app sandbox.

## Install

1. Requires **AppSync Unified** (or a self-signing tool);
2. Download `iLegacyGPT-1.1.0.ipa` and install with i4Tools / ipatool / any self-signing tool;
3. Open settings and fill in provider, base URL, port and API key;
4. Optional: configure a search API (e.g. Exa) in the same settings sheet, then tap the 联网 chip to pick 自动 or 强制.

## Known limitations

- armv7 only (32-bit);
- the follow-up round after a tool call does not replay the raw `tool_calls` protocol messages, so the model sees search results as injected context (this avoids reasoning-model 400s);
- history images are 320 px thumbnails, originals are not persisted;
- reasoning levels only work if your gateway honours the parameters;
- first load is a bit slow on old hardware.

# 中文说明

**给老 iOS 设备用的大模型客户端。** 取代 v1.0.0，在 iPad 4（iPad3,4 / A6X / armv7 / iOS 10.3.4）上实测可用。

这个版本加了**联网搜索**，并修掉了 0.7.x 反馈的两个问题（思考关不掉、Markdown 表格不渲染）。

## 功能

- 连接任意 **OpenAI 兼容接口**：provider / Base URL / 端口 / API Key 全部可配，模型列表自动拉取；
- **联网搜索**三态：关闭 / 自动 / 强制；
  - **自动**走**真 function calling**——请求里带 `web_search` 工具，由模型自己决定搜不搜，结果以带编号的来源列表呈现、可点开；
  - **强制**永远先搜，再把资料注入回答；
  - 网关不支持 `tools`（400/422）时自动降级到搜索规划器，不会报错；
- **流式输出** + 可展开的**思考过程**（关闭 / 低 / 中 / 高）；
  - 选「关闭」现在是真的关（显式下发 `enable_thinking: false`），不再依赖网关默认值；
- **Markdown**：表格（支持列对齐，宽表可横向滑动）、任务列表、嵌套列表、删除线、裸链接、代码块；
- **时间上下文**：把当前时间和时区告诉模型，问「今天 / 最新」时会用正确日期去搜；
- **会话归档**：左侧抽屉按「今天 / 近 7 天 / 更早」分组，左滑重命名 / 删除；
- **图片上传**：相册选图发送，历史保留 320px 缩略图；
- **数据只存本机**：无账号、无遥测，Key 与会话都在 App 沙盒内。

## 安装

1. 需要设备已越狱并安装 **AppSync Unified**（或可自签名）；
2. 下载 `iLegacyGPT-1.1.0.ipa`，用爱思助手 / ipatool / 自签名工具安装；
3. 打开后进设置填写 provider、Base URL、端口、API Key；
4. 可选：在同一设置页配置搜索 API（如 Exa），然后点输入框上方的「联网」芯片切到「自动」或「强制」。

## 已知限制

- 只编了 armv7（32 位），64 位设备装不上；
- 工具调用后的第二轮不带原始 `tool_calls` 协议消息，资料以系统消息注入（这样能避开思考模型的 400）；
- 历史图片仅存 320px 缩略图，原图不落盘；
- 思考档位是否生效取决于所用网关；
- 老设备首次加载略慢。
