# v1.1.1

## Added

None.

## Changed

- `MinimumOSVersion` raised from 8.0 to 10.0. The UI bundle requires ES2015 and the stylesheet requires CSS custom properties, so installation on iOS 8 or 9 resulted in a blank page. Declaring 10.0 prevents installation on systems the build cannot run on.

## Fixed

None. The application code is identical to v1.1.0.

## Known issues

- the follow-up request after a search tool call carries the retrieved documents as context; the `tool_calls` messages are not replayed;
- conversation images are stored as 320 px thumbnails;
- reasoning levels take effect only if the configured gateway accepts the parameters;
- the IPA is unsigned and requires AppSync Unified or re-signing.
