# v1.0.0

First public release. Verified on iPad 4 (iPad3,4) running iOS 10.3.4.

## Added

- OpenAI-compatible endpoint configuration: provider, base URL, port, API key and model list.
- Streaming output with an expandable reasoning block; reasoning levels off, low, medium and high.
- Web search in three modes: off, auto and force. `auto` advertises a `web_search` tool and lets the model decide when to call it; results are attached as numbered sources with links.
- Markdown rendering: tables with column alignment, task lists, nested lists, strikethrough, links and code blocks.
- Session archive grouped by today, last 7 days and earlier, with rename and delete.
- Image input from the photo library; history keeps a 320 px thumbnail.
- Current time and time zone supplied with every request.
- armv7 and arm64 slices in one package, deployment target iOS 9.3.
- The UI bundles as a single HTML file and is compiled to ES5.
- Application icon set generated from a single lossless source, without cropping or re-composition.

## Changed

None; this is the first release.

## Fixed

None; this is the first release.

## Known issues

- armv7 on iOS 9.3.5 / 9.3.6 (iPad 2, iPad 3, iPhone 4S, iPod touch 5) is not verified on hardware.
- arm64 on iOS 9 / 10 (iPhone 5s through iPhone 7) is not verified on hardware.
- The follow-up request after a search tool call carries the retrieved documents as context; the `tool_calls` messages are not replayed.
- Conversation images are stored as 320 px thumbnails; the originals are not kept.
- Reasoning levels depend on the configured endpoint accepting the parameters.
- The IPA is unsigned and requires AppSync Unified or re-signing.

# v1.0.0

首个公开版本。已在 iPad 4（iPad3,4，iOS 10.3.4）上验证。

## 新增

- OpenAI 兼容接口配置：provider、Base URL、端口、API Key 与模型列表。
- 流式输出与可展开的思考过程；思考档位为关闭、低、中、高。
- 联网搜索三种模式：关闭、自动、强制。`auto` 注册 `web_search` 工具，由模型决定何时调用；检索结果以带编号的来源列表附加在回答后。
- Markdown 渲染：表格（支持列对齐）、任务列表、嵌套列表、删除线、链接、代码块。
- 会话归档按今天、近 7 天、更早分组，支持重命名与删除。
- 支持从相册发送图片，历史记录保留 320px 缩略图。
- 每次请求附带当前时间与时区。
- 同一安装包内含 armv7 与 arm64 两份切片，部署目标 iOS 9.3。
- 界面打包为单个 HTML 文件，并编译为 ES5。
- 应用图标集由同一份无损源图生成，未裁切、未重新构图。

## 变更

无，本版本为首次发布。

## 修复

无，本版本为首次发布。

## 已知问题

- armv7 + iOS 9.3.5 / 9.3.6（iPad 2、iPad 3、iPhone 4S、iPod touch 5）未经真机验证。
- arm64 + iOS 9 / 10（iPhone 5s 至 iPhone 7）未经真机验证。
- 检索工具调用后的续接请求以上下文形式携带检索结果，不重放 `tool_calls` 消息。
- 会话图片以 320px 缩略图保存，不保留原图。
- 思考档位取决于所配置接口是否接受相关参数。
- IPA 未签名，需 AppSync Unified 或自行签名。
